# Периодический локальный коммит и push

Необязательный macOS LaunchAgent из `scripts/periodic_commit_push.py` проверяет этот checkout по расписанию. Установите его после того, как `main` начнёт отслеживать `origin/main`:

```sh
python3 scripts/periodic_commit_push.py install --interval-minutes 30 --quiet-minutes 10
```

По умолчанию проверка выполняется каждые 30 минут; все изменённые файлы должны оставаться без изменений 10 минут. Агент работает только в ветке `main` с ожидаемым GitHub origin и пустым индексом. Пока удерживается любая блокировка проекта, агент ждёт. Он пропускает защищённые пути и файлы размером более 1 МиБ, запускает настроенные хуки prek, добавляет подходящие изменения проекта, создаёт коммит с временной меткой и отправляет его в `origin/main`. Force push не выполняется. Если push не удаётся, локальный коммит остаётся для проверки.

Планировщик устанавливается явно для текущего пользователя в `~/Library/LaunchAgents` и не запускается при входе в систему; первая проверка происходит через заданный интервал. Журнал находится в игнорируемом файле `.run/periodic-commit-push.log`. После push тесты запускает GitHub Actions; планировщик сам тесты не запускает.

Управление LaunchAgent:

```sh
python3 scripts/periodic_commit_push.py uninstall
```

Однократный запуск вручную:

```sh
python3 scripts/periodic_commit_push.py run
```

Автоматизация пропускает файлы окружения, локальные данные, кэши, учётные данные, ключи и сертификаты, базы данных и большие файлы. Она не анализирует произвольное содержимое файлов на наличие секретов. Проверяйте `.gitignore` и не храните секреты в checkout.
