# Документация

В этой папке собраны материалы проекта для пользователей и рецензентов. Краткая точка входа — [корневой README](../README.md). Основной язык — английский; ключевые документы для людей имеют русскую версию с `.ru.` в имени файла.

Структура следует облегчённому подходу Diátaxis: сначала практические задачи, затем объяснения, справочные материалы и свидетельства по проекту. Файлы оставлены на прежних местах, чтобы сохранить существующие ссылки.

## Начало работы

- **Запуск проекта:** [практическое руководство](RUNBOOK.ru.md) по настройке, получению данных, офлайн-повтору и диагностике.
- **Демонстрация workflow:** [синтетическое демо](SYNTHETIC_DEMO.ru.md) запускает конвейер на явно помеченных вымышленных данных.
- **Устройство проекта:** [архитектура и поток данных](ARCHITECTURE.ru.md) описывают источники, временную доступность и оценку.
