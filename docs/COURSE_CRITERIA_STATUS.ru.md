## Критерии минимального проходного балла

Рубрика выделяет жирным шрифтом шесть обязательных критериев. Ни один из них пока не подтверждён как завершённый результат курса:

| Обязательный критерий | Статус | Текущие свидетельства |
|---|---|---|
| Краткое описание задачи в README | Частично | README описывает прогноз GLD/SLV; принятие проверяющим неизвестно. |
| Источники данных и признаки из лекций | Частично | [Словарь признаков](FEATURE_DICTIONARY.ru.md) связывает источники и признаки с модулями 1–5; теперь заморожен полный эксперимент с COT на реальных данных, но зачёт критерия не подтверждён. Словарь описывает пять производных примеров; требование 20+ признаков не выполнено. |
| Общий датафрейм и заданные наборы признаков | Частично | Последний замороженный эксперимент использовал 1 916 строк аналитической таблицы, 1 906 строк с целевой переменной и 211 дат публикаций после фильтра доступности; см. [отчёт полного запуска](FULL_RUN.ru.md). Зачёт критерия зависит от проверяющего. |
| DecisionTree или RandomForest | Частично | В каноническом сравнении COT модели DecisionTree и RandomForest сопоставлены с mean baseline; по MAE на validation выбрана mean. Два расчёта текущего кода совпали по 20 числовым хэшам. Ранние outputs без подтверждённого происхождения исключены и обновлены. См. [отчёт полного запуска](FULL_RUN.ru.md). Принятие критерия проверяющим не подтверждено. |
| Векторная симуляция и примерная доходность капитала | Частично | Код симуляции с фиксированным номиналом есть; замороженный эксперимент содержит векторное приближение и симуляцию с ограничением капитала; обе дали отрицательный net holdout. Зачёт критерия зависит от проверяющего. |
| Экспортированные скрипты и сквозной ноутбук | Частично | Скрипты и ноутбук есть; ячейки настройки и offline workflow выполнены из каталога `notebooks/`; полноценный запуск Jupyter kernel и чистая установка без прогретого кэша не подтверждены (см. [финальный QA](FINAL_QA.ru.md)). |

**Покрытие обязательных критериев:** подтверждённые результаты курса — 0, частично — 6, открыто — 0. Свидетельств реализации стало больше; статус «подтверждено» зависит от рубрики и проверяющего. Права повторного использования/распространения данных не подтверждены; чистая установка без cache и полноценный запуск notebook kernel также не проверены (см. [независимый QA](FINAL_QA.ru.md)).

Перечень по коду «источник → доступность → преобразование → роль в модели», пять примеров производных признаков и сопоставление модулям курса приведены в [словаре признаков](FEATURE_DICTIONARY.ru.md). Полная EDA и эксперимент с COT на 1 916 строках описаны в [результатах](EDA_FINDINGS.ru.md) и [отчёте полного запуска](FULL_RUN.ru.md). Для оценки дополнительной ценности COT нужен отдельный корректный ablation; данных о будущей прибыльности нет.

| Статус | Критерии | Значение |
|---|---:|---|
| Подтверждено | 0 | Завершённый результат подкреплён наблюдаемыми свидетельствами. |
| Частично | 20 | Есть отдельные свидетельства реализации; зачёт результата курса не подтверждён. |
| Открыто | 16 | Не хватает артефакта, эксперимента, результата или решения проверяющего. |
| Заблокировано | 0 | В матрице рубрики отдельные критерии так не классифицированы; фактические блокеры данных описаны там же. |
| Отложено | 0 | Отдельно не классифицировано; необязательные бонусные критерии сейчас открыты. |
| **Всего** | **36** | Все критерии рубрики, включая бонусные. |

В проекте есть замороженное исследование с COT, purge-holdout, две симуляции с издержками и совпадающий offline replay; остаются ограничения винтажей данных и прав на использование. Синтетическое демо и тесты ПО не являются финансовыми свидетельствами.
