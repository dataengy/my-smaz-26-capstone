**Проверено:** 2026-11-21 по [официальной рубрике проекта курса](https://raw.githubusercontent.com/DataTalksClub/stock-markets-analytics-zoomcamp/main/projects/README.md). [English version](COURSE_CRITERIA_STATUS.md).

Это датированная сводка свидетельств в рабочей папке, а не прогноз оценки и не решение проверяющего. **Частично** означает, что артефакт или код есть, но требуемые результаты курса или их приёмка не подтверждены. [Полная матрица критериев](../openspec/specs/capstone/spec.md#course-acceptance-evidence-matrix) содержит ссылки на свидетельства и причины. Обновляйте эту сводку при каждом запуске навыка `capstone-verification`.

## Критерии минимального проходного балла

Рубрика выделяет жирным шрифтом шесть обязательных критериев. Ни один из них пока не подтверждён как завершённый результат курса:

| Обязательный критерий | Статус | Текущие свидетельства |
|---|---|---|
| Краткое описание задачи в README | Частично | README описывает прогноз GLD/SLV; принятие проверяющим неизвестно. |
| Источники данных и признаки из лекций | Открыт | Полное сопоставление источников и признаков с лекциями и выполнение не проверены. |
| Общий датафрейм и заданные наборы признаков | Частично | Реализация признаков и наборы есть; реальный общий набор не создан. |
| DecisionTree или RandomForest | Частично | Код кандидатов есть; обучение на реальных данных и прогнозы не проверены. |
| Векторная симуляция и примерная доходность капитала | Частично | Код симуляции с фиксированным номиналом есть; реальные результаты и зачёт критерия не подтверждены. |
| Экспортированные скрипты и сквозной ноутбук | Частично | Скрипты и ноутбук есть; полный запуск от загрузки до последних сделок не проверен. |

**Покрытие обязательных критериев:** подтверждено — 0, частично — 5, открыто — 1. Частичная реализация не означает, что баллы получены.

## Свидетельства по всей рубрике

| Статус | Критерии | Значение |
|---|---:|---|
| Подтверждено | 0 | Завершённый результат подкреплён наблюдаемыми свидетельствами. |
| Частично | 16 | Есть отдельные свидетельства реализации; зачёт результата курса не подтверждён. |
| Открыто | 20 | Не хватает артефакта, эксперимента, результата или решения проверяющего. |
| Заблокировано | 0 | В матрице рубрики отдельные критерии так не классифицированы; фактические блокеры данных описаны там же. |
| Отложено | 0 | Отдельно не классифицировано; необязательные бонусные критерии сейчас открыты. |
| **Всего** | **36** | Все критерии рубрики, включая бонусные. |

В проекте нет реальных рыночных снимков, EDA на реальных данных, обученных результатов на реальных данных, метрик бэктеста или сравнения с бенчмарком. Синтетическая демонстрация и автоматические проверки ПО не являются свидетельствами финансового исследования.
