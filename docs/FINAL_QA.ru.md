# Независимый финальный QA

**Дата проверки:** 2026-11-21. Это ограниченный независимый аудит текущего checkout и зафиксированных real-data пакетов; он не заменяет проверку курса или юридическую консультацию.

## Результат

Блокер достаточности данных для эксперимента снят: аудит CFTC подтверждает 213 полных пар дат отчётов с 2022-10-25 по 2026-11-17 по консервативному cutoff; поля совпадают с проверенными годовыми архивами. Происхождение результатов установлено: `artifacts/full-cot-current-code-20261121/` и `artifacts/full-cot-model-comparison-20261121/` содержат одинаковые хэши кода моделирования/исследования и выбирают mean (validation MAE 0,036398; MAE `forest_3` — 0,036521). Новый freeze текущего кода выполнен дважды и совпал по всем 20 числовым результатам; fingerprints записаны для 60 входных файлов. Ранее корневые outputs без замороженных code/config/input evidence выбирали `forest_3` и содержали 1 964 строки признаков с 2020-12-29, до публичного запуска PRE 2022-10-20; они исключены из допустимого эксперимента. Корневые generated outputs теперь синхронизированы с текущим bundle. Двуязычный основной отчёт указывает mean как канонический результат.

Offline workflow notebook формирует сигналы на 2026-11-20. В текущем frozen-результате после purge остаётся 565/185/191 дата train/validation/test на ETF; на validation выбрана mean. Это свидетельство воспроизводимости, но не доказательство будущей доходности.

Предыдущая установка dev extras прошла в новом `/private/tmp/capstone-qa-venv` с uv cache проекта и установила 129 пакетов lock-файла на тот момент. Новая попытка в чистом окружении с текущим lock на 216 пакетов завершилась ошибкой при сборке проекта: build isolation не смог получить `setuptools>=75` с PyPI из-за DNS. Ранее и полностью холодный uv cache не смог загрузить CPython с GitHub. Поэтому offline clean install не подтверждена; прежний cache-backed результат относится к старому lock.

Ячейки настройки и offline workflow ранее выполнялись напрямую через IPython shell notebook из `notebooks/`; `nbconvert --to script` также завершился. Полная попытка `nbclient` на временной копии, где была пропущена необязательная сетевая загрузка, остановилась до запуска ячеек: sandbox не разрешил bind локального порта. Это ограничение среды. Перед защитой обновите сохранённый output notebook по каноническому результату mean; не запускайте refresh в офлайн-демо.

Это не подтверждает права на распространение данных проекта или коммерческое применение. Числовая квота, SLA и стабильный публичный rate limit не подтверждены. Оставляйте Yahoo-снимки локально до выяснения прав.
- **Binance Spot:** [официальные REST-документы](https://developers.binance.com/en/docs/products/spot/rest-api) описывают веса отдельных route, IP-level лимиты, обязательный backoff при HTTP 429 и возможность бана 418; текущие значения доступны через `exchangeInfo`. Лимиты динамические/настраиваемые, их нужно читать во время работы. Проверка не установила применимую Binance-сущность/условия или право распространения CSV; см. [условия Spot API](https://developers.binance.com/en/docs/products/spot/PROD-TERMS-OF-USE). Код использует публичные klines без авторизации и ограниченную пагинацию, но пока не реализует backoff по 429/Retry-After и учёт заголовков квот.
- **CFTC:** [FAQ COT](https://www.cftc.gov/MarketReports/CommitmentsofTraders/index.htm) сообщает, что токены API сейчас не выдаются и обычно API доступен без токена, если не злоупотреблять; числовая квота не указана. Отдельное [соглашение CFTC для FTP submission portal](https://accountcreation.cftc.gov/TermsOfUseAgreement.aspx) говорит, что размещённая на сайте государственная информация находится в общественном достоянии и может копироваться с атрибуцией, но оно относится к порталу подачи данных и не должно автоматически распространяться на каждое использование PRE/API. Сохраняйте атрибуцию и отделяйте timestamps строк API от фактической публикации статического отчёта.
- **FRED:** не используется; проверка винтажей и доступности на момент публикации не выполнена.
