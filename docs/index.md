# Documentation

This directory describes the project for users and contributors. English is the authoritative version; Russian companion documents use `.ru.md` and link back to their English source. Dates and evidence apply equally to both versions. The [root README](../README.md) is the entry point for the research and course checklist.

The organization follows the intent of [Diátaxis](https://diataxis.fr/): distinguish practical instructions from explanations and reference material. It is a lightweight convention, not a claim of full framework adoption.

- **How-to:** [Local setup and research runbook](RUNBOOK.md).
- **Reference:** [Make and Just command guide](COMMANDS.md).
- **Explanation:** [Architecture and data flow](ARCHITECTURE.md).
- **Reference and evidence:** [COT publication evidence](COT_RELEASE_EVIDENCE.md) and [changelog](CHANGELOG.md).

The project is work in progress: no complete real-data experiment or financial performance has been established. See the root README for current limitations and `.ai/` for agent operations, plans and backlog.
