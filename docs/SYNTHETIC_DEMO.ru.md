# Запуск синтетического демо

Этот офлайн-демо-сценарий создаёт файлы с форматом, похожим на источники, в `data/synthetic/human-demo/`, передаёт их через реальные функции построения признаков, хронологического выбора модели и симуляции сделок, а затем открывает визуальный отчёт. Все значения вымышлены. Время публикации COT придумано для демо и не является подтверждением публикаций CFTC. Метрики на синтетическом тестовом отрезке показывают только работу кода и ничего не говорят о качестве торговли.

## Запуск

Из корня проекта после установки Python 3.11+ и `uv` выполните:

```sh
make setup
make demo-synthetic
```

Команда использует детерминированные параметры из [`config/synthetic_demo.yml`](../config/synthetic_demo.yml) и записывает повторно используемые синтетические CSV и манифест происхождения в `data/synthetic/human-demo/`. Чтобы открыть отчёт в браузере, откройте `artifacts/synthetic-demo/index.html`; в macOS можно выполнить `open artifacts/synthetic-demo/index.html`. В отчёте есть заметное предупреждение о синтетических данных, графики вымышленных цен, прогнозов на синтетическом тесте и симулированного капитала. Команда не скачивает данные и не меняет настройки исследования на реальных данных.

Чтобы проверить демо без открытия браузера:

```sh
make test-demo-synthetic
```

Тест пишет файлы во временный каталог и проверяет наличие входов, машиночитаемой сводки, предупреждения и всех трёх построенных графиков. `make test` также выполняет этот тест в составе полного набора. `just verify` запускает те же тесты, а также проверку lock-файла и компиляцию.

## Создаваемые файлы

- `data/synthetic/human-demo/*.csv` и `manifest.json`: сгенерированные входные снимки и манифест с seed и временным предупреждением. Эти файлы исключены из Git; команда выше создаёт их заново.
- `artifacts/synthetic-demo/index.html`: визуальная демонстрация этапов.
- `artifacts/synthetic-demo/summary.json`: метаданные запуска, признаки, даты разбиения и метрики, явно обозначенные как синтетические.
- `artifacts/synthetic-demo/*.png`: рисунки из отчёта для повторного использования только с заметной пометкой о синтетическом содержимом.

Генератор использует seed `2026`, даты сессий NYSE для ETF и индексов, ежедневные даты для вымышленных криптосерий и явно проставленные придуманные еженедельные публикации COT. Он запускает те же построители признаков (включая временное объединение публикаций), хронологическое разделение train/validation/test, выбор модели, событийную симуляцию, векторную симуляцию с фиксированным номиналом и бенчмарк buy-and-hold. Демонстрационный конфиг использует уменьшенную сетку моделей, чтобы ускорить запуск; основной конфиг исследования не меняется.

Не используйте эти файлы для выводов исследования, заявлений о доходности на защите или инвестиционных решений. Для эксперимента на реальных данных следуйте [инструкции запуска](RUNBOOK.ru.md); ещё нужны настоящие снимки поставщиков и достаточные подтверждения времени публикаций COT для конкретных отчётов.
