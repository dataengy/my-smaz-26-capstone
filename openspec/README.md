# Specification baseline

[OpenSpec](https://github.com/Fission-AI/OpenSpec) is the selected specification-driven framework. [`specs/capstone/spec.md`](specs/capstone/spec.md) records initial human-readable requirements and acceptance scenarios; [the implementation plan](../.ai/IMPLEMENTATION_PLAN.md) tracks orchestration and evidence. The project has not established CLI installation, version, automatic discovery or validation. Check official installation and command documentation before adding the CLI; record the version and validation output only after a successful run.
