# Local Codex session accounting

Run `make usage` (or `uv run --locked python scripts/codex_usage.py --project .`) to inspect aggregate metadata from the local sessions tree configured by `codex_sessions_root` in `config/settings.yml` (default `~/.codex/sessions`). `--settings` selects another YAML settings file and `--sessions-root` overrides that configured path. No network request is made. The script does not print messages, paths, identifiers, credentials or per-session records. It reads files locally, which may contain private conversation content; do not share or commit those files.

A session is directly attributed when its recorded working directory resolves to the project or a descendant. A session with no working directory can instead be attributed through a known parent session. A session with an explicit external working directory is excluded, even if it has a project parent. This is conservative and can omit project work in external worktrees or sessions not present in this store. The session identity and parent fields themselves have not been independently verified as a complete lineage mechanism.

Files with the same session ID count once. Conflicting project and external identities or parent IDs cause that identity to be excluded. When duplicate files report different usage values, that session's usage is excluded and the conflict is counted. Unreadable files, malformed lines and files without IDs are counted. The file, duplicate and identity-conflict counts describe the scanned tree, not necessarily the project. A missing root is reported explicitly. A null sum means no session provided that field, not zero usage.

The script takes the last valid `event_msg.info.total_token_usage` per file; when that legacy form is absent, it uses the last `token_usage_record.thread_token_usage`. It prefers the legacy form if both occur, without adding them. A shape-only inspection of 30 recent local files on 2026-11-21 found both forms in 28; their last shared fields matched in 24 and differed in 4. This observation does not establish whether either counter is cumulative, complete, current or billable. Counts may overlap across parent and child sessions. Do not interpret their sums as verified spend or coverage; no cost is estimated. The model field is only the last recognized model string per file and is not an allocation of tokens by model.

Langfuse and MLflow are not configured by this script. An external integration would require verified interfaces, clear scope, privacy controls and an explicit reason; raw logs must not be exported by default.
