# COT point-in-time availability

1. Inspect current CFTC source documentation and record URL, terms, format, retrieval time, coverage and revision behavior. Keep observations distinct from retrieval and publication timestamps.
2. Establish public availability for each included report using independently confirmed release evidence, including exceptional and holiday delays. Do not equate the Tuesday observation date with publication.
3. Join only reports available by the precise signal cutoff in a declared timezone. Exclude unconfirmed releases; report affected dates and coverage instead of fabricating an availability time.
4. Test a release after cutoff, an exceptional delay, an absent confirmation and a normal release. Save compact provenance and test evidence without committing financial data.
